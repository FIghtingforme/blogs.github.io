### 内存不足创建swap空间

#### 痛点：云服务器的内存太小，又想要极致性价比

#### 解决方案：
##### 创建swapfile的大文件放在swap下



```
- 创建swap空间：
- 
	- 创建swapfile空间 ==>  转为swap  ==>  激活swap并加入linux   ==>  配置永久挂载
	
	
	- if        
	- 
		- input file
	
	- 
	- of
	- 
		- output file
		
	
	- bs
	- 
		- block size 每次读取多少
	
	- 
	- count     
	- 
		- 读取次数
	
	- dd  if=/dev/zero  of=/tmp/swapfile  bs=1M  count=1000
	- 
	- 
	- mkswap  /tmp/swapfile
	- 
	- free -h
	- 
	- chmod  600  /tmp/swapfile
	- 
	- mkswap /tmp/swapfile
	- 
	- swapon  /tmp/swapfile

		

	- free -h
	- 

	- 
	- 先卸载当前的 Swap 文件 
	- 
		- swapoff /tmp/swapfile 
		
		- 
	- 使用 swapon -a 命令（它会读取 /etc/fstab 中的所有 swap 条目并尝试挂载） 
		- 
		- swapon -a
		
	- vim /etc/fstab（修改）

		- /swapfile   swap   swap    defaults    0    0 
	
	
	- free -h 
		
		- 再次查看挂载情况
```
